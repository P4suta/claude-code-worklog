# Cc-worklog

Generate work reports from Claude Code session logs.

## Installation

```sh
git clone https://github.com/P4suta/claude-code-worklog.git
cd claude-code-worklog
cargo install --locked --path crates/worklog-cli
```

## Usage

```sh
worklog --help
```
